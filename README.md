# The Forge

Kosthold og trening i én app: dagsplan med makrobudsjett, matvarer, lager, vektlogg, styrke, dagbok og
månedsmål.

**Bruk appen:** https://athellion.github.io/forge/

- Alt lagres på din egen enhet. Ingen konto, ingen sky.
- Installer den: åpne lenken i Chrome på Android og velg «Installer app» / «Legg til på startskjermen»
  (iPhone: Del → «Legg til på Hjem-skjerm»; PC: Edge → Apper → «Installer dette nettstedet som en app»).
- Fungerer uten nett når den er åpnet én gang.
- Ta sikkerhetskopi jevnlig (Profil → Sikkerhetskopi) og legg den i Google Drive eller lignende.
  Appen minner deg på det hver uke.

Matvaredata er hentet fra Oda, Meny og produsentene. Tallene er per 100 g.
